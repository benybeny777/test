## 実装順タスク

### T9. 画像→3Dバックエンドの再決定（利用者判断待ち）

TripoSRは女性3体すべての実画面で顔・髪・衣装が崩れ、marching cubes解像度256と正面原画投影でも完成品質へ届かなかったため採用を撤回した。次のいずれを選ぶか利用者が決めるまで、完成キャラクター生成の実装を進めない。

1. GPU要件をVRAM 16GB以上へ上げ、`microsoft/TRELLIS-image-large` を非商用依存なしの経路で再検証する
2. 3D生成を外部ツールで行い、本製品はVRMインポートと表情・配信を担当する（製品からクラウドAPIは呼ばない）
3. 3Dをやめ、原画を保持できる2D/2.5Dキャラクター方式へ仕様変更する
4. 商用3D生成サービスの利用を認める。費用・APIキー・プライバシー・オフライン喪失を別途設計する

着手条件: 利用者が上記の方向と、VRAM 8GB・完全ローカルという既存条件のどちらを優先するか決定すること。
