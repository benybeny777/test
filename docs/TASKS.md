# TASKS.md — 未完了作業と着手順

着手前に [AGENTS.md](../AGENTS.md) → [SPEC.md](../SPEC.md) を読む。このファイルは未完了作業と着手条件だけを管理する。変更・比較・検証の履歴は [PR #21](https://github.com/benybeny777/test/pull/21)、現行方式と到達条件は [SPEC.md 4.2](../SPEC.md#42-生成パイプライン) を正本とする。完了した項目はここから除き、完了記録を複写しない。

## 承認済みの前提

- 現在の目的は、このWindows環境で高品質なキャラクターを同一パイプラインから作れること。品質判定とモデルの採否変更は利用者が行う。
- ComfyUIを管理下で使用し、DINO/SAMを維持する。Qwen-Image-Edit-2511の通常局所補完への採用は承認済み。Layered・Florence-2等の比較承認を製品採用と扱わない。製品はクラウドAPIを呼ばない。
- 口の現状は暫定承認され、追加造形調整は保留。口の連続動作・原画保持の回帰確認と、他部位の作業は継続する。
- 対象原画は女性A・むぎ・PicoAgentの「実写・物理演算テスト」（`photoreal-prototype`）。実写は実験用で公式キャラと分ける。別の実写原画や同名候補へ取り違えず、入力SHAで照合する。
- 承認済み旧候補と原画は保持する。耳・閉眼など個別候補への承認を、全キャラ・全工程の品質承認へ広げない。

## T11. 共通パイプラインとリグの未完了事項

着手順は以下とする。閉眼の通常統合だけで全体完成とは扱わない。

1. **現在の通常補完を実走・検証する。** 隠れ顔／耳の補完版3はむぎで実行中。版3を含む現行全工程の3キャラ実走・品質確認は未完了。既に完走した旧版の閉眼4工程とは区別する。生成後に原画保持、補完領域、首／襟のscene所有、小角度動作を確認する。
2. **閉眼の品質未達を直す。** 肌下地の上縁・髪際、半閉眼の下端、まつげの厚みと連続開閉を検証する。左右の白目・下まぶたなど独立素材の不足も残る。原画と並べ、左右別の開き0／0.5／1と連続往復で確認する。
3. **SPEC 4.2の機能単位へ素材分割を進める。** 首の影・襟／胴体の接続、髪束、袖・手・上腕／前腕などは未完成。候補の意味競合・欠落を原寸で検証し、同じ画像の複製や固定座標の分割で部位数を満たさない。観測不能・遮蔽・原画にない部位を区別する。
4. **隠れ素材と独立関節を成立させる。** 首／襟、肩／袖、腕、髪の動作露出範囲を補完し、接続領域・支点・親子・クリップを保存する。現在の可視素材と共通変位場を、独立関節の完成と呼ばない。未補完部位を無理に独立可動化しない。
5. **真の世代参照切替を実装する。** 表示読者を変更しない公開世代へ固定する方式は未完了。最終rig2dの起動時退避復旧と読込失敗時の旧表示保持だけでは、二段階renameの短い未配置期間を解消できない。全工程の起動復旧、実行状態と公開済み世代の分離、再生成失敗後の旧公開世代の再表示、HTTP読込中の世代保持も残る。
6. **共通動作を回帰確認する。** 本体・ブラウザ確認画面の共通レンダラーを維持し、無音時の閉口、`MouthOpenY × MouthForm`、左右まばたき、小角度の首・体・腕・髪、透明境界、キャラ切替時の資源解放を検証する。追加口造形は保留したまま、既存動作の破綻は修正する。

## T12. 再現性・全キャラ品質とスマホ確認

- T11の修正を同一処理・同一設定で対象3原画へ適用する。キャラ名による分岐や専用座標を追加しない。現行版の全3キャラ完成は未実走・未承認として扱う。
- SPEC 4.2に従い、未知の立ち絵を保留検証用に1枚以上用い、既知3体だけへの適合と量産時の再現性を区別する。
- 原寸顔クロップ・原画比較・全身、左右別の半閉／閉眼、口2軸の格子点と連続往復、首／襟／肩の小角度往復、白黒市松背景、キャラ切替時のメモリを検証する。コード検査と実画面・利用者の品質判断を分けて記録する。
- [スマホ用ギャラリー](CHARACTER_GALLERY.md)を実際に検証した現行成果物へ更新する。未合格・比較用・実験用を明示し、旧3Dや失敗候補を完成例として見せない。
- 品質未達が残る場合は実測・試した対策・必要な判断を提示する。モデルの無断変更・画質低下による見かけ上の完了はしない。

## 現在の対象外・再開条件

- **macOS／Linux、VRM、OBS、PicoAgent本体への組み込み・既存Pico形式への変換**は現在対象外。将来の可能性だけを理由に対応実装や抽象化を加えない。Live2D関連の既存PoCは削除せず保持する。
- **追加アクションと追加の口造形調整**は利用者からの追加指示を待つ。現在必要な待機・口パク・まばたきの品質確認とは分ける。
- **動画生成、配布署名、自動更新などの配布方針**は現在のキャラクター品質作業へ混ぜず、利用者が対象化した時点で要件を確認する。未実測のVRAM見積もりだけを理由に不可能と決めない。
- `30_live`の未追跡原画・生成物や対象外の別実写候補を削除・上書きしない。
