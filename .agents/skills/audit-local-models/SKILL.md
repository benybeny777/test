# ローカルモデルと依存を監査する

クラウドAPIを使わない製品なので、**同梱するモデルの権利と実動作がそのまま製品リスクになる**。採用してから不適合が判明すると設計ごとやり直しになるため、必ず採用前に通す。

## 適用範囲を決める

依頼の言葉から範囲を絞る。範囲を宣言してから調べる。

| 依頼 | 範囲 |
|---|---|
| 「モデルを採用したい」「どれを使う」 | 対象モデル候補すべて。ライセンスを最優先 |
| 「依存を更新して」 | Cargo・Python パッケージ・推論エンジンのバイナリ |
| 「販売前に確認して」 | 全件。同梱物の実体まで照合する |

## 1. ライセンスを最初に確認する

**性能や品質より先にここを見る。** 不適合なら他をいくら調べても無駄になる。

モデルごとに次を確定し、出典URLとあわせて記録する。

- ライセンス名と版
- **商用利用の可否**
- **地域制限**（EU / 英国 / 韓国などを除外する条項を持つモデルがある）
- **モデル重みの再配布可否**（同梱して配布できるか。できないなら初回ダウンロード方式にする）
- **生成物の権利**（出力に条件が付くか）
- ベースモデルと finetune で条項が分かれていないか

推論エンジン本体（llama.cpp / whisper.cpp / stable-diffusion.cpp）が MIT 系でも、**そこへ載せる GGUF の条項は別**。個別に確認する。

不適合なものは候補から外し、**外した理由も記録する**。理由が消えると、次に見た人が同じ検討をやり直すか却下済みの案へ戻る。

## 2. 版を確認する

- 外部依存は原則として**公式 LTS または長期保守安定版**。LTS 相当が無ければ安定版 latest
- 推論エンジンとモデルは**公式の最新安定版へ追従**する
- **CUDA を使う Python ランタイムは Python 3.12 に統一する。** GPU・CUDA・PyTorch・CUDA拡張の公式 wheel が同時に対応する組み合わせだけを採る。Python 単体の最新版へ上げない
- `Cargo.toml` / `Cargo.lock` を変更したら `cargo audit` を実行し、保守終了などの情報警告と実際の脆弱性を分けて評価する

## 3. 実機で動くことを確かめる

**「動くはず」で採用しない。** このプロジェクトの制約は VRAM 8GB であり、公式が推奨する VRAM を満たさない構成が多い。

モデルごとに実測して記録する。

- **ピーク VRAM**（`nvidia-smi` を生成中に観測する）
- 1回あたりの所要時間
- OOM せずに連続実行できるか（1回通っても2回目で落ちる構成がある）
- ディスク使用量

**取得前に判定する**: 機能の利用意思と OS・CPUアーキテクチャ・GPU種別・必要能力を確認してから落とす。**CUDA 版は CUDA 対応 NVIDIA GPU を確認できた場合だけ取得する。** AMD / Intel / GPU なし環境で CUDA 版を予備目的に落とさない。

## 4. 同梱物の実体を照合する

- 同梱実行ファイル・モデル・ランタイムが**本アプリ管理下の専用ディレクトリ**にあるか。既存の手動インストール環境を書き換えていないか
- 実行時データが `app_data_dir` 配下にあるか
- **旧版・退避・staging・`.part`・完了済み再開キャッシュが残っていないか。** 新版の検証が成功してから旧版を消す。失敗時は復旧に必要な物だけ残す
- リポジトリにモデルやエンジンバイナリが混入していないか（`.gitignore` を確認する）
- ハッシュとサイズが記録と一致するか

## 5. 文書へ反映する

調べただけで終わらせない。**同じ作業内で**書く。

| 内容 | 書く場所 |
|---|---|
| 採用モデルとライセンス名・商用可否・地域制限・再配布可否 | `SPEC.md` の「ローカルモデル構成」表 |
| 却下した候補と理由 | 同上 |
| 版・取得方法・セットアップコマンド | `docs/DEVELOPMENT.md` |
| 設定キー（モデル名・バックエンド等） | `docs/SETTINGS.md` |
| 未解決のまま残した項目 | `docs/TASKS.md` |
| 実測した VRAM・所要時間・容量 | PR 本文 |

容量は**十進の MB / GB** で書く。バイト数の単独表示や併記をしない。外部仕様が MiB / GiB でも 10 進へ換算する。

## 停止条件

次の場合は実装へ進まず、利用者へ報告して判断を仰ぐ。

- 第一候補がすべてライセンス不適合だった
- どの候補も VRAM 8GB で完走しなかった
- 再配布不可のモデルしか選べず、初回ダウンロード方式でも条項を満たせない

黙って条件の悪い代替へ降格しない。何がどう劣るかを具体的に伝える。
